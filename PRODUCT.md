# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The author, as a personal tool. They use it on their own phone, often one-handed and on the move: in a store with a shopping list, or ticking off tasks during the day. No other audiences are confirmed.

## Product Purpose

Simple Lists is an installable, offline-first PWA for shopping and task lists. Its hierarchy is Organizations → Projects → Lists → Items. Success means a list is always at hand, opens instantly with or without a connection, and gets out of the way while the user adds, checks and clears items.

## Positioning

No account, no cloud. Data lives only in this device's IndexedDB: no sign-in, no server, no tracking. This is the one commitment future work must never compromise. Sync, accounts, analytics, or any feature that sends list data off the device conflicts with it.

## Operating Context

- Mostly a phone in portrait orientation, launched standalone from the home screen. Desktop is supported too: right-click opens the editor.
- Usage is short and frequent, often with one hand and divided attention, such as walking store aisles or switching between tasks.
- Data moves between devices only through manual JSON export and import (Settings → Data).

## Capabilities and Constraints

- **Hierarchy:** Organizations, Projects and Lists are "entities" that share name, color (coral, amber, lime, teal, sky, indigo, violet, rose), manual order, and the same screens. Items belong to a list.
- **Items:** tap to check or uncheck. Checked items sink to the bottom, most recent first. Each list remembers whether checked items are shown (the eye toggle).
- **Input:** "Add items" turns every line break into an item, and pasting several lines creates one item per line.
- **Gestures:** swipe left to delete, with Undo in a toast. Hold to edit, or hold and move to reorder. Cards also have a ⋯ menu.
- **Theme:** light, dark or system, applied before first paint.
- **Offline and updates:** a service worker caches the app, and an "Update available" prompt handles new versions (`registerType: 'prompt'`).
- **Backups:** export and import, with replace or merge modes. Backups from a newer schema are rejected.
- **Stack (existing):** React 19, Vite, TypeScript, Dexie (IndexedDB), react-router, motion, dnd-kit, vite-plugin-pwa, Inter Variable. Deployed on Vercel with SPA rewrites.
- **Language:** English only (`lang="en"`). No localization planned.

## Brand Commitments

- The name is "Simple Lists", and it is a standalone product. The repository folder name ("simplesuite") does not imply a suite or a shared identity.
- The copy voice in the existing UI is plain, short and direct ("Everything is stored only on this device.").

## Evidence on Hand

- App icons and favicon are in `public/` and are generated by `scripts/generate-icons.mjs`.
- There are no users, testimonials, metrics or marketing claims, so none may be invented.

## Product Principles

1. **Local and private by construction.** Nothing leaves the device unless the user explicitly exports it.
2. **Speed over features.** Adding, checking and clearing items should take the fewest possible taps and no waiting, even offline.
3. **One-handed, distracted use is the default scene.** Design for a thumb and a glance, not for focused sitting.
4. **Simple stays simple.** The hierarchy exists for separating contexts, and each screen should still feel like just a list.

## Accessibility & Inclusion

No product-specific requirement has been set beyond solid baseline practice. The existing code already uses ARIA labels, radiogroups, a polite live region for toasts, and system theme support.
